Introducao

Introducao a cadeira Programacao Web II, cadeira lecionada no curso de Engenharia e Ciencia de Computadores no ISUTC 3Ano, II Semestre.

Objectivos de Aprendizagem

Apos a frequencia da Disciplina, os alunos deverao ser capazes de:
  • Descrever Arquiteturas, Ferramentas e Standards usados na programação Web
  • Conceber e implementar componentes de Frontend e Backend de uma aplicação Web
  • Determinar a arquitetura e modelo adequado para uma aplicação Web consoante requisitos apresentados
  • Avaliar aspetos éticos e de segurança relativos à concepção e uso de sistemas web

Plano Tematico: Unidades

  1. Fundamentos de Programação Web
  2. Programação de Frontend
  3. Programação de Backend
  4. Ética e Segurança
