# Exercicio 01 - Aula 03 (HTML Semantico)

Criar uma pagina HTML com uma lista de compras, as listas devem conter os seguintes elementos:

- **Carnes**
  - Frango
  - Vaca
  - Peixe
- **Vegetais**
  - Cenoura
  - Alface
  - Tomate
- **Frutas**
  - Banana
  - Laranja
  - Maca

**NOTA:** Usar HTML Semantico!
