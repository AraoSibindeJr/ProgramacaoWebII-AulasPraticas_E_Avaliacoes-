# Programação Web II

Repositório destinado à documentação do processo de aprendizagem da disciplina de **Programação Web II**, frequentada no 3.º ano do curso de **Ciência da Computação**.

Este repositório reúne, de forma organizada e progressiva, as actividades desenvolvidas ao longo do semestre, incluindo aulas práticas, exercícios, trabalhos, projectos, avaliações e exemplos de código.

## Objectivos

- Consolidar conhecimentos de programação e desenvolvimento web.
- Aplicar conceitos teóricos através de exercícios e projectos práticos.
- Desenvolver boas práticas de programação e organização de código.
- Documentar a evolução técnica ao longo da disciplina.
- Desenvolver competências de resolução de problemas e desenvolvimento de aplicações web.
